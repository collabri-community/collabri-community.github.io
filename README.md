# collabri-io.github.io

Landing site for the `collabri` permanent-identifier prefix at
[w3id.org/collabri](https://w3id.org/collabri).

This repo is the redirect target for the w3id `.htaccess` rules. It hosts:

- `/` &mdash; identifier landing page
- `/schema/` &mdash; Collabri ontology and schema terms (LinkML-generated HTML/TTL/RDF)
- `/doc/{id}` &mdash; controlled-document viewer entries

Served via GitHub Pages on the `main` branch.
